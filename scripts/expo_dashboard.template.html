Floppy Expo Build Tracker

Every screen in expo/ and the components it renders: how much is React Native, how much is shared with the web build, and how much is signed off in the component register.

How the bars are calculated
Native conversion
Read from each file's imports and JSX. React Native imports react-native and has no DOM markup. Neutral composes other components without its own primitives. Mixed / DOM still contains HTML tags, className or browser globals.
Code ownership
Shared: a frontend/ file the web build also imports (including .native/.web pairs). Frontend, native only: lives in frontend/ but no web page uses it yet. Reused native: native-app code used by 2+ pages. Unique native: native-app code used by one page only, the first place to look for duplicated solutions.
Sign-off
Signed off means the file is listed on a - Sign-off: line in docs/ui/component-register.md (the owner's review). Registry verified means docs/ui/architecture-registry.json records iOS and Android as verified (agent evidence, not yours); partial means one platform.
Page tree
Each page lists every file reachable from its native screen (and shared view), following .native/.ios variants as Metro does. Other pages' screens are not followed. Sign-offs apply to the file, so one sign-off counts on every page that uses it.
