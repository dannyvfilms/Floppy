Version decision:
Issue #591 makes the browser dependency local and deterministic. It does not
require a library upgrade. Version 0.21.3 is the bundle tested in PR #758.
Review a later package version as a separate change so a scanner regression has
one clear cause.

Update procedure:
1. Select an exact upstream release.
2. Review its release notes, license, browser API, and supported formats.
3. Replace the bundle, license, versioned file names, and this record together.
4. Update the template reference and the static-library contract tests.
5. Test barcode scanning with local network access disabled.
6. Run the focused tests, the full application suite, lint, CodeQL, and the
   built-image check before merge.
