Core integration workflows

Common recipes for searching, tracking, scrobbling, and connecting AI coding assistants.

1. Search media catalog
curl --request GET \
  --header "X-API-Key: YOUR_API_TOKEN" \
  "https://YOUR_FLOPPY_HOST/api/v1/search/movie/?search=Dune"
2. Track or update media
curl --request POST \
  --header "X-API-Key: YOUR_API_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{"title": "Dune", "status": 1, "score": 9}' \
  "https://YOUR_FLOPPY_HOST/api/v1/media/movie/"
3. Scrobble music listen (ListenBrainz standard)
curl --request POST \
  --header "Authorization: Token YOUR_API_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{"listen_type": "single", "payload": [{"listened_at": 1700000000, "track_metadata": {"artist_name": "Pink Floyd", "track_name": "Time", "release_name": "The Dark Side of the Moon"}}]}' \
  "https://YOUR_FLOPPY_HOST/apis/listenbrainz/1/submit-listens/"
4. Connect AI Assistant via FastMCP
claude mcp add floppy -- docker exec -i -e FLOPPY_TOKEN="YOUR_API_TOKEN" floppy uv run --no-sync python -m floppy_mcp

Reference cheat sheet

Category Path Description
System Info GET /api/v1/info/ Instance version, status, and configuration
Media Entries GET, POST /api/v1/media/{type}/ Query or create user media tracking records
Item Detail GET, PATCH, DELETE /api/v1/media/{type}/{source}/{id}/ Manage individual item status, score, progress
Search GET /api/v1/search/{type}/?search=... Query provider catalog metadata
History GET /api/v1/history/ Chronological consumption events & scrobbles
Lists GET, POST /api/v1/lists/ Custom smart lists and curated collections
List membership PUT, DELETE /api/v1/media/{type}/{source}/{id}/lists/{list_id}/ Add or remove a title by provider id; unknown titles are created
Collection GET, POST /api/v1/collection/ Physical & digital media inventory tracking
Collection by provider id PUT, DELETE /api/v1/media/{type}/{source}/{id}/collection/ Mark a movie as owned; episodes use /media/tv/{source}/{id}/{season}/episodes/{episode}/collection/
Music Plays POST /api/v1/music/bulk-plays/ Batch log album tracks and plays
Webhooks POST /integrations/{service}/webhook/ Plex, Jellyfin, Emby, Kodi, and Seerr sync (service: plex, jellyfin, emby, kodi, seerr)
