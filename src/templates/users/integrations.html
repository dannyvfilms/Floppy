Setup Instructions

Kodi Integration

Connect Kodi to automatically track your watching progress.

Setup Instructions

  1. You will need TMDB and/or TVDB metadata sources enabled in Kodi so that external IDs are included in webhook payloads.
  2. Download and install the HTTP Scrobbler add-on.
  3. In Kodi, go to Settings > Services > Control and enable Allow remote control via HTTP.
  4. In the HTTP Scrobbler add-on settings, set the webhook URL to: Tip: open the Kodi web interface at http://<kodi-ip>:8080 to configure the add-on — easier than using the remote. {# djlint:off #}
    {% include "app/icons/copy.svg" with classes="w-5 h-5 text-[var(--color-text-muted)] group-hover:text-indigo-400 transition-colors" %}
    {# djlint:on #}
  5. Leave the username and password fields blank.
  6. Enable the following events: Start, Stopped, and Finished.
  7. An item is marked watched when playback reaches 80% or Kodi reports a Finished event.

Stremio Integration

Install the Floppy Scrobbler addon in Stremio to mark movies and episodes as in progress the moment playback starts. Pair it with the Stremio import on the Import page, which syncs watched state from your Stremio library every 2 hours.

Setup Instructions

{% url 'stremio_addon_manifest' request.user.token as stremio_addon_path %} {% absolute_app_url stremio_addon_path as stremio_addon_url %}
  1. Copy your personal addon URL: {# djlint:off #}
    {% include "app/icons/copy.svg" with classes="w-5 h-5 text-[var(--color-text-muted)] group-hover:text-indigo-400 transition-colors" %}
    {# djlint:on #}
  2. In Stremio, open Addons, paste the URL into the search box at the top, and click Install.
  3. Floppy must be reachable from your Stremio device over HTTPS (plain HTTP only works for localhost).
  4. Playback start marks the item in progress; the recurring library import marks items watched.
